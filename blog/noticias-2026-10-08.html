1Ingeniería

OpenGrid impulsa herramientas abiertas para planificar redes eléctricas

Linux Foundation crea una base interoperable para compartir modelos, datos y herramientas de planificación.

La Linux Foundation presentó OpenGrid, una iniciativa abierta para modernizar la planificación de redes eléctricas y reducir barreras de interoperabilidad entre herramientas comerciales y de código abierto. El proyecto plantea una arquitectura común de datos, estándares, API y un repositorio de conjuntos de datos preparados para modelado.

Su primera aplicación prevista, OpenGrid Translator, está en desarrollo para 2027 y buscará facilitar el intercambio de datos y modelos entre plataformas. La iniciativa resulta relevante para ingeniería eléctrica, expansión de infraestructura y análisis de demanda industrial.

2Industria

OpenChain presenta un marco SBOM para software automotriz

La versión 1.0 propone criterios compartidos para inventariar componentes y dependencias del software en vehículos.

Linux Foundation publicó OpenChain Automotive SBOM Framework 1.0, una guía abierta para crear e intercambiar listas de materiales de software en la industria automotriz. Define campos recomendados, criterios de calidad y escenarios de intercambio entre fabricantes y proveedores.

El marco complementa formatos existentes como SPDX (ISO/IEC 5962), sin sustituirlos. Su propósito es facilitar la trazabilidad de dependencias, la revisión de ciberseguridad y la comunicación técnica a lo largo de la cadena de suministro.

3Software libre

Europa analiza soberanía digital y gobernanza del código abierto

Un informe de Linux Foundation Europe examina el papel del software abierto ante la adopción de IA.

Linux Foundation Europe difundió el informe State of Open Source in Europe 2026, centrado en soberanía tecnológica, gobernanza y uso de tecnologías abiertas. Según la investigación, el 94 % de las organizaciones consultadas considera importante la soberanía digital para su estrategia tecnológica.

El documento también identifica desafíos en el mantenimiento de proyectos, la gobernanza y el cumplimiento normativo a medida que crece el uso de inteligencia artificial. Sus conclusiones ofrecen contexto para equipos que evalúan dependencias abiertas, colaboración y sostenibilidad del software.
