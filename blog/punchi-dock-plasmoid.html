Punchi Dock 0.6.0: un dock ligero para Plasma 6 que ahora conversa mejor con tus ventanas

La versión 0.6.0 mantiene el foco en lanzadores y herramientas rápidas, pero suma soporte opcional de ventanas, contenedores más flexibles, mejor integración con paneles y una apariencia mucho más adaptable al tema de KDE Plasma.

Punchi Dock empezó como una idea muy concreta: tener un dock de lanzadores para Plasma 6 que fuera claro, configurable y fácil de instalar sin tocar la configuración global del escritorio. Con la versión 0.6.0 el proyecto crece bastante, pero conserva esa intención: sumar una herramienta útil al escritorio, no pelearse con Plasma.

Qué cambia en la versión 0.6.0

La novedad principal es el soporte opcional de ventanas. Cuando se activa desde la página Ventanas, Punchi Dock puede usar el modelo de tareas de Plasma para activar, minimizar, cerrar, anclar o desanclar ventanas desde el dock. También puede mostrar ventanas abiertas que todavía no están fijadas como items temporales.

Esto no convierte al proyecto en un gestor de tareas completo. La primera implementación evita las miniaturas vivas y usa un popup liviano con título, icono, estado activo y botón de cierre. Es una base más estable para Wayland y para Plasma 6, sin depender de herramientas externas como xdotool, wmctrl o xprop.

La idea sigue siendo la misma: un dock práctico para lanzar, ordenar y acceder rápido, ahora con una capa opcional para interactuar con ventanas cuando tiene sentido.

Lanzadores, contenedores y módulos

Punchi Dock permite mezclar aplicaciones, contenedores, separadores, espacios fijos o flexibles, reloj, calendario y Papelera. Cada app puede tener nombre, icono y comando propio; los contenedores pueden armarse manualmente, desde una carpeta del sistema o desde categorías de aplicaciones KDE como desarrollo, juegos, multimedia, internet, oficina, sistema, utilidades o gráficos.

El selector de iconos también creció: puede buscar en el tema actual de KDE, temas heredados, hicolor, exports de Flatpak y archivos de imagen. Eso ayuda especialmente cuando se fijan ventanas temporales o se crean contenedores con aplicaciones instaladas como Flatpak.

Stack principal

KDE Plasma 6 · Wayland · QML · JavaScript · TaskManager · kpackagetool6 · GPL-3.0-or-later

Apariencia más flexible

La configuración visual ahora está más ordenada y cubre iconos, espaciado, zoom, espacio reservado para el zoom, opacidad, etiquetas, sonidos, popups, indicadores activos, orientación y forma del dock. La forma puede seguir el tema de Plasma o usar estilos recto, redondeado, píldora y personalizado.

También se agregaron presets para el largo máximo y el grosor del dock. El grosor funciona como alto en orientación horizontal y como ancho en orientación vertical; el largo puede quedar automático, a pantalla completa, tres cuartos, media pantalla, un tercio, un octavo o personalizado. Fuera de un panel, una protección evita deformaciones al mover el dock desde el modo de edición de Plasma.

Edición de elementos

La forma recomendada de editar el dock es abrir la configuración del plasmoide y entrar en Elementos. Desde esa página se pueden agregar apps, contenedores, separadores, espacios, reloj, calendario y Papelera sin editar archivos a mano. El clic derecho también incluye una acción para abrir la configuración de Punchi Dock desde los items principales.

Para usuarios técnicos, la vista Advanced JSON sigue disponible para revisar, copiar o modificar configuraciones completas. Internamente, Punchi Dock guarda sus elementos en:

~/.config/punchi-dock/dock_items.json

Si el archivo no existe, crea una configuración inicial con Mozilla Firefox, Home, Konsole, LibreOffice, Gráficos, Configurar dock, Papelera, GitHub, Calendario, un separador y Reloj.

Ventanas sin perder el foco

El soporte de ventanas viene desactivado por defecto. Al habilitarlo, los items de aplicación pueden activar o minimizar su ventana asociada; si hay más de una ventana, el dock puede mostrar una lista compacta. Desde el clic derecho se agregan acciones comunes como restaurar, minimizar, cerrar o abrir la lista de ventanas.

También hay una opción para publicar la geometría del icono al modelo de tareas de Plasma. Cuando KWin y el efecto del compositor lo soportan, Plasma puede usar esa información para animar minimizar o restaurar hacia el icono correspondiente del dock.

Contenedores, reloj, calendario y Papelera

Los contenedores reemplazan la idea inicial de carpetas rígidas por un modelo más flexible. Pueden abrirse como popup en cuadrícula o lista, cargar contenido manual o tomar elementos desde carpetas y categorías KDE. Para el uso diario, eso permite agrupar trabajo, sistema, desarrollo o multimedia sin llenar el panel principal.

El proyecto sigue evitando cargar plasmoides externos dentro del dock. En su lugar usa módulos internos como clock, calendar, trash, separator y spacer. El calendario puede funcionar en modo visual o texto, el reloj puede configurarse como digital o analógico y la Papelera soporta estado lleno/vacío, apertura de trash:/, vaciado desde clic derecho y arrastre de archivos.

Integración con panel

La versión 0.6.0 también mejora el uso cuando Punchi Dock está anclado a un panel de Plasma. Puede ocultar su fondo, rellenar espacio libre, alinear contenido y ocultar reloj o calendario cuando no conviene repetir información que ya está en el panel.

El modo de tema Plasma queda como base recomendada: usa colores y comportamiento visual del entorno cuando corresponde, pero deja opciones manuales para quienes quieren ajustar opacidad, radio, indicadores o forma.

Instalación local y empaquetado

Punchi Dock se puede instalar para el usuario actual mediante kpackagetool6, sin usar sudo. La forma más directa es descargar punchi-dock.plasmoid desde el release de GitHub o instalar desde una copia local del repositorio:

git clone https://github.com/PunchiSoft/punchi-dock-plasmoid.git
cd punchi-dock-plasmoid
chmod +x install-plasmoid.sh
./install-plasmoid.sh

También se puede generar un paquete instalable .plasmoid:

chmod +x build-plasmoid.sh
./build-plasmoid.sh

El paquete queda disponible en dist/punchi-dock.plasmoid. El ID del plasmoide es org.kde.plasma.punchi-dock, la versión documentada aquí es 0.6.0 y el mínimo declarado para Plasma es 6.0.

Compatibilidad y límites claros

El plasmoide está orientado a KDE Plasma 6 o superior y especialmente a Wayland. No modifica la configuración global de Plasma, no toca plasma-org.kde.plasma.desktop-appletsrc y no depende de utilidades externas para manipular ventanas.

Hay límites intencionales: todavía no muestra miniaturas vivas, no reemplaza al gestor de tareas completo de KDE y no carga plasmoides externos. Sus indicadores de ejecución para lanzadores configurados siguen siendo simples, útiles para casos comunes, pero el seguimiento profundo de tareas queda en manos de Plasma.

Para quién es

Punchi Dock encaja bien si quieres un dock visual para organizar accesos frecuentes, separar grupos de trabajo, mantener pequeños módulos a mano y, si lo necesitas, interactuar con ventanas abiertas sin abandonar el estilo de Plasma. También sirve como base de aprendizaje para estudiar plasmoides modernos: QML, configuración de widgets, archivos JSON de usuario, modelo de tareas y empaquetado .plasmoid.

Como proyecto PunchiSoft, sigue la misma dirección de otras herramientas del sitio: hacer más comprensibles tareas técnicas del escritorio Linux, con una interfaz concreta y un alcance honesto.
